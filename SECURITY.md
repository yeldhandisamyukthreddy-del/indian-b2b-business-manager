# Security policy

VyaparEasy runs entirely on the user's device and has no server. The main risks are malicious input (for example a crafted backup file) and the desktop wrapper.

## Reporting a vulnerability

Please **don't open a public issue**. Report privately through [GitHub security advisories](https://github.com/yeldhandisamyukthreddy-del/indian-b2b-business-manager/security/advisories/new) and include steps to reproduce. You should get a reply within 7 days.

## Supported versions

Only the latest release receives fixes.
